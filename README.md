# AP Bio Unit 3 Review

Study guide, practice questions, flashcards and free-response prompts for AP Biology Unit 3, topics 3.1–3.5.

Open `index.html` in a browser, or run a local server:

```bash
python3 -m http.server 8000
```

To add questions or flashcards, edit `js/data.js`. See `AGENTS.md` for project details.
